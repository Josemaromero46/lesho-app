# Imágenes de referencia de las señas

Esta carpeta es opcional. Si colocas aquí una imagen con el nombre de una clase,
la captura la mostrará como guía visual de cómo se hace esa seña mientras la
persona graba.

## Cómo usar

- Nombra cada archivo con el nombre exacto de la clase, en mayúscula:
  - `A.png`, `B.png`, ..., `Ñ.png`, `INICIO.png`, `FIN.png`, `REPOSO.png`
  - Para señas dinámicas: `HOLA.png`, `GRACIAS.png`, etc.
- Formatos aceptados: `.png`, `.jpg`, `.jpeg`.
- Tamaño sugerido: cuadradas (por ejemplo 400x400). La interfaz las redimensiona.

Si no hay imagen para una clase, la captura simplemente muestra el nombre de la
seña en grande, sin referencia visual. No es obligatorio tener imágenes para
grabar.

## Por qué conviene tenerlas (para las 50 señas)

La lección más importante del proyecto: **todas las personas deben hacer cada
seña de la MISMA forma.** Si una persona hace TRABAJO distinto a otra, o incluso
la misma persona la hace distinta entre tomas, el modelo no puede aprenderla. Una
imagen (o mejor, un video corto) de referencia por seña, definida con la asesoría
LESHO, mantiene a todos consistentes. Vale mucho la pena antes de grabar las 50.

## Las 50 señas dinámicas (nombre exacto del archivo)

Colocá `<NOMBRE>.png` (o `.jpg`) por cada una. Faltan todas por ahora.

- Cortesía: `HOLA` `ADIOS` `GRACIAS` `POR_FAVOR` `PERDON`
- Respuestas: `SI` `NO` `BIEN`
- Necesidades: `AGUA` `COMER` `BAÑO` `DORMIR` `AYUDA` `DOLOR` `HAMBRE` `ENFERMO`
- Personas / familia: `MAMA` `PAPA` `FAMILIA` `AMIGO` `NIÑO` `MAESTRO` `DOCTOR`
- Verbos: `QUERER` `NECESITAR` `TENER` `DAR` `PERDER` `VENIR` `JUGAR` `ESTUDIAR` `APRENDER` `COMPRAR` `ESPERAR`
- Lugares: `CASA` `ESCUELA` `HOSPITAL` `TIENDA` `CALLE` `TRABAJO`
- Emociones / estados: `FELIZ` `TRISTE` `ENOJADO` `CANSADO` `MIEDO`
- Tiempo: `HOY` `MAÑANA` `AYER` `DIA` `NOCHE`
