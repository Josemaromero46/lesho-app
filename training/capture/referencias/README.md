# Imágenes de referencia de las señas

Esta carpeta es opcional. Si colocas aquí una imagen con el nombre de una clase,
la captura la mostrará como guía visual de cómo se hace esa seña mientras la
persona graba.

## Cómo usar

- Nombra cada archivo con el nombre exacto de la clase, en mayúscula:
  - `A.png`, `B.png`, ..., `Ñ.png`, `INICIO.png`, `FIN.png`, `REPOSO.png`
  - Para señas dinámicas: `HOLA.png`, `GRACIAS.png`, etc.
- Formatos aceptados: `.png`, `.jpg`, `.jpeg`.
- Tamaño sugerido: cuadradas (por ejemplo 400x400). La interfaz las redimensiona.

Si no hay imagen para una clase, la captura simplemente muestra el nombre de la
seña en grande, sin referencia visual. No es obligatorio tener imágenes para
grabar.
